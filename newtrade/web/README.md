# 股票交易系统 Web 界面

这是一个基于Go和原生JavaScript的股票交易系统Web界面，提供了完整的股票交易功能。

## 🚀 快速开始

### 1. 启动服务器
```bash
cd newtrade/web
go run main.go
```

服务器将在 **http://localhost:8081** 启动

### 2. 访问界面
在浏览器中打开 **http://localhost:8081**

## ✨ 主要功能

### 📊 市场行情
- 实时显示股票价格、涨跌幅、成交量、市值
- 美观的卡片式布局
- 点击股票卡片自动填充交易表单

### 💼 交易操作
- **买入/卖出订单**: 选择股票、类型、数量、价格
- **实时价格**: 自动填充当前市场价格
- **表单验证**: 确保订单信息完整有效

### 📋 订单管理
- **挂单列表**: 显示所有待成交订单
- **订单状态**: 实时更新订单状态
- **取消订单**: 支持取消自己的挂单

### 💰 投资组合
- **总资产概览**: 现金余额 + 持仓市值
- **持仓详情**: 每只股票的持有数量、成本、盈亏
- **实时更新**: 自动计算未实现盈亏

### 📜 交易历史
- **完整记录**: 所有成交的交易记录
- **详细信息**: 时间、股票、类型、数量、价格、金额

### 👤 用户管理
- **多用户支持**: 切换不同用户ID
- **数据隔离**: 每个用户独立的数据
- **权限控制**: 只能操作自己的订单

## 🔧 技术特性

### 后端 (Go)
- HTTP服务器 + RESTful API
- 集成交易引擎
- 自动撮合功能
- 实时数据更新

### 前端 (JavaScript)
- 原生JavaScript，无框架依赖
- 响应式设计
- 实时数据刷新 (每5秒)
- 错误处理和用户反馈

### 样式 (CSS3)
- 现代化UI设计
- 渐变背景和毛玻璃效果
- 响应式布局
- 动画和交互效果

## 📱 响应式设计

- **桌面端**: 双列布局，完整功能展示
- **移动端**: 单列布局，优化触摸操作
- **自适应**: 自动调整不同屏幕尺寸

## 🔄 自动撮合

系统支持价格-时间优先的自动撮合：
- 买单匹配最低卖价
- 卖单匹配最高买价
- 支持部分成交
- 实时更新投资组合

## 🐛 故障排除

### 常见问题

1. **"加载股票数据失败"**
   - 检查服务器是否启动
   - 确认端口8081未被占用
   - 查看浏览器控制台错误信息

2. **页面样式异常**
   - 确认CSS文件路径正确
   - 检查浏览器兼容性

3. **API请求失败**
   - 检查网络连接
   - 确认服务器状态
   - 查看服务器日志

### 调试模式

打开浏览器开发者工具 (F12)：
- **Console**: 查看JavaScript日志和错误
- **Network**: 监控API请求和响应
- **Elements**: 检查HTML结构
